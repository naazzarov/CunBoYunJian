# CunBo YunJian 直播剪辑工作室

[English](README.md) · 简体中文

将直播录像自动转成可供人工审核的短视频：录制画面和声音 → 生成与视频对应的 SRT 字幕 → 根据知识库智能选段 → 自动剪辑。审核与各平台发布由人工完成。

这是可以运行的初测版本。优先用一个类别的内容验证选段质量，再扩展知识库。

**当前版本：1.0.0-beta.1 好友测试版。** 这台 Mac 已准备好本地模型和启动配置，使用 [中文好友测试指南](GROUP-TEST.zh-CN.md) 开始跨网络测试。

## 中文支持

- 界面默认简体中文，右上角可切换英语，浏览器会记住选择。
- 「剪辑说明语言」独立于界面语言，默认中文。可选择英语或与字幕语言一致，控制新生成的标题、类别与选段理由。
- 字幕保留发言原语言，时间戳与录像一致。中文知识卡支持检索，知识库可导入、导出 JSON。
- 既有任务与用户填写的知识不会自动翻译。若模型误用规则标题，系统会使用所选字幕作为标题回退，该标题可能保留原文，审核时需检查。

## 本地启动

需要 Python 3.12、FFmpeg（包含 ffprobe）和支持 OpenAI 兼容 API 的模型服务。推荐使用多语言 Qwen 模型；演示小模型的选段质量需要人工评估。

```sh
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt -r requirements-asr.txt
ollama pull qwen3:8b
export LLM_BASE_URL=http://127.0.0.1:11434/v1
export LLM_MODEL=qwen3:8b
export ASR_MODEL=small
export ASR_LANGUAGE=zh
python -m uvicorn app.main:app --host 127.0.0.1 --port 8766 --workers 1 --no-proxy-headers
```

访问 `http://localhost:8766`。全中文直播可设置 `ASR_LANGUAGE=zh`；中英混合或其他语言可取消该变量，让模型自动识别。`tiny`、`base`、`small` 等是多语言模型；名称以 `.en` 结尾的模型只适合英语，不能用于中文转写。首次使用会下载语音模型。

`.env.example` 是配置示例，程序不会自行读取 `.env`；请在 shell 或 Docker Compose 中加载配置。完整的部署、访问密钥和 OBS 设置见 [英文开发文档](README.md)。

## 首次测试

1. 打开「知识库」，添加入门模板并修改为你的受众和选段要求。也可以导入 `examples/zh-pilot-brief.json`（这些卡是可修改的规则模板，并非已核实事实）。
2. 选择一段短直播录像。电脑可使用网页屏幕录制，需同时共享音频；手机可上传设备自带录屏或回放。长直播可使用 OBS。
3. 设置任务名称、片段时长、数量、竖屏画布和说明语言。品牌、人名和术语可填入专有名词栏。如有字幕，添加与录像对应的 SRT 文件。
4. 点击「生成剪辑」。处理完成后查看片段、选段理由与引用的知识卡版本，下载视频、字幕或全部文件。
5. 人工审核并记录原因。在「审核与改进」中选择「起草知识经验」，完善后保存入库。新任务使用更新的知识，历史任务保留原快照。
6. 审核通过后，通过各视频平台人工发布。

## 多设备使用范围

Windows、macOS、Android 和 iOS 可通过浏览器使用同一工作区。手机主要用于上传、查看、审核和下载；网页跨应用录屏受系统与浏览器限制，可使用系统录屏后上传。服务端完成转写与剪辑，不要求手机运行模型。跨设备访问需要部署到可访问的 HTTPS 地址并配置工作区访问密钥。当前仓库没有原生安装包，也不会因推送到 GitHub 自动上线。

## 知识库如何改进

初期只做一个类别，分别记录受众、剪辑规则、已核实事实与已审核案例。每张事实卡写明依据；每个案例说明通过或不通过的原因。审核反馈不会自动训练模型，确认后的经验可手动加入知识库，影响后续选段。要衡量质量提升，应在相同测试录像上比较通过率、上下文完整性和事实准确性。
