# 村播云剪 · 指定工具链

本指南说明公开源码的安装与运行方式。内部需求资料不包含在公开版本中；实际能力以官方源码和运行验证为准。

## 一期工作流

1. OBS 录制画面与音频，或手机上传屏幕录像／直播回放。桌面浏览器录屏必须共享声音。OBS 自动化通过已有带密码的 WebSocket 接口接入；录制目录通过环境变量限制。
2. 官方 FunClip v2.1.0、FunASR v1.4.0 和中文 Paraformer 热词模型转写。独立子进程退出后释放语音模型内存，再进入选段。输出 SRT、纯文本、匿名说话人时间段。当前好友服务的实际引擎请看界面状态，不会把备用 Whisper 显示成 FunASR。
3. Ollama / 兼容的本地 Qwen3 服务依照知识快照与七类提示词选段。以字幕 cue ID 建立符合时长的短／中／长区间选项，由 LLM 选择有完整语义的区间，程序计算时间。选项只验证时长，不代表内容已经合格。无合适内容可以返回空结果；不合规短片段触发纠错重试，并保存原始候选和过滤原因。
4. jieba 使用版本化商品词典提取 Top 20 词频与疑问原话。结果是审核候选，不会自动升级为产品事实。
5. FFmpeg 剪辑；可选 auto-editor v3 时间线删除静音。保留字幕覆盖的语音，重新映射字幕，使用短音频淡入淡出；如果精简后低于最短时长，则保留原片段。可选 MoviePy 1.0.3 + ImageMagick 渲染硬字幕。
6. 下载视频、SRT、标签、关键词和方案。人工检查字幕与上下文，在剪映专业版精修，再通过五个平台官方后台手动发布。软件不会替用户点击发布。

## 本地配置

API 的环境变量及访问密钥放在忽略的 .env 或 data/group-config.json，不提交 Git。参考 requirements-first-phase.txt 安装 Python 3.10 依赖；FunClip 源码必须来自官方 v2.1.0 标签。保留现有工作区数据库，不要让两套处理服务同时写入同一个数据库。

指定 ASR_BACKEND=funclip、FUNCLIP_PATH、FUNCLIP_PYTHON 启用官方转写适配器。MODELSCOPE_CACHE 与 MODELSCOPE_HOME 分别指向权重缓存及 SDK 配置目录，HF_HOME 指向 Hugging Face 缓存。AUTO_EDITOR_BINARY 指向官方二进制；本项目实测版本为 31.7.2。该版本导出模式为 --export v3，不是 json，也不能直接照搬手册中的旧版本命令。EDITOR_PYTHON 指向安装了 MoviePy 的解释器；IMAGEMAGICK_BINARY 与 SUBTITLE_FONT 指向本机程序与中文字体。Windows、macOS 路径各自配置，不硬编码到源码。

网页可在 Windows、macOS、iOS、Android 浏览器使用。移动端通过文件上传接入，不假定手机浏览器具备桌面录屏权限。Mac 好友测试通过免费临时 HTTPS 隧道共享，Mac 必须在线；重启分享后可能产生新链接。

## 知识库起步

先测试一个真实类别。界面的六区产品模板覆盖规格、溯源、工艺、价格、场景／疑问、证据。只有用户提供并核实的资料才能保存为事实；证书、报告需写清来源、日期和适用范围。模板占位文字须替换。每个任务保存知识版本快照；审核意见经人工整理后才能加入知识库。

## 二期边界

RAGFlow + BGE-large-zh-v1.5 + Qdrant、Qwen3-VL 与 pyJianYingDraft 是手册列出的二期组件，不阻塞一期测试。当前 8 GB Mac 未部署这组服务；RAGFlow 手册推荐 16 GB 内存。扩展到满足资源要求的已有电脑后，须检查官方版本、配置引用来源，并测试 Jianying 版本兼容。没有用户证书和检测报告时，不伪造资料或标记此项已验收。

使用官方仓库和下载源。保持全本地免费路线，不配置付费 Qwen 或 DeepSeek API。GitHub 保存源码、提示词、词典和工程文档，不保存模型权重、客户录像或凭据。
